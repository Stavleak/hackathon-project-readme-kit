# [Жоба атауы]

Хакатон жобасының README файлына арналған Stavleak үлгісі.

Жақшадағы өрістерді өз тексеруіңіздің нәтижелерімен ауыстырыңыз. Қолданылмайтын баптауларды және жобаңызға сәйкес келмейтін оқу мысалын алып тастаңыз. Төмендегі `text` блоктарында дайын орнату командалары емес, толтыруға арналған өрістер берілген. Құпиясөздерді, токендерді және жеке деректерді қоспаңыз.

## Құпия мәндерсіз баптаулар

Қолданбаңыз шынымен пайдаланатын атауларды ғана қалдырыңыз. Әрқайсысының мақсатын, міндеттілігін және мәнін алудың келісілген тәсілін көрсетіңіз.

- `APP_MODE`: [қолданба режимі; демо үшін қажет пе].
- `DEMO_DATA_PATH`: [қауіпсіз оқу деректеріне жол].
- `SERVICE_API_KEY`: [тек қажет болса; шектеулі тесттік қолжетімділікті қайдан алу керек, кілт мәнінсіз].

Баптау файлының мысалында қауіпсіз ашық параметрлер мен толтыру орындары болуы керек. Нақты құпияларды рұқсат етілген арнамен бөлек беріңіз.

## Кіріс және күтілетін нәтиже

```text
input_reference: [файл немесе сұраудың нақты мазмұны]
action: [экран мен басқару элементі немесе API әдісі мен маршруты]
expected: [нақты жауап немесе байқалатын нәтиже]
comparison: [салыстыру ережелері, реті және рұқсат етілген өрістер]
no_match_or_invalid_input: [кіріс және күтілетін әрекет]
```

Бөлмелер сүзгісіне арналған оқу мысалы. Деректер ойдан шығарылған, нақты бөлмелер мен брондауларды білдірмейді. Мысалды өз сценарийіңізбен ауыстырыңыз.

Бастапқы деректер:

```json
{"rooms":[{"id":"demo-room-a","equipment":["projector","whiteboard"]},{"id":"demo-room-b","equipment":["projector"]}]}
```

Кіріс:

```json
{"required":["projector","whiteboard"]}
```

Күтілетін жауап:

```json
{"rooms":["demo-room-a"]}
```

`{"required":["microphone"]}` кірісі үшін `{"rooms":[]}` күтіледі.

## Соңғы коммиттен бөлек тексеру жазбасы

README файлын жаңартып, соңғы коммитті жасаңыз, содан кейін толық идентификаторын тапсыру формасына жазыңыз. README файлының тұрақты сілтемесін де коммит жасалған соң сақтаңыз. README бар коммиттің идентификаторын сол файлға қоспаңыз: өзгерісті сақтау үшін жаңа коммит керек болады.

Тексеруден кейін келесі блокты іс-шараның рұқсат етілген жұмыс кеңістігінде бөлек толтырыңыз:

```text
submission_commit: [толық идентификатор]
readme_permalink: [көрсетілген коммиттегі README]
checked_environment: [орта және нұсқалар]
input: [қауіпсіз кіріс]
steps: [орындалған реттілік]
expected: [күтілетін нәтиже]
observed: [нақты нәтиже]
blocked_at: [нақты қадам немесе none]
author_assistance: [қажет көмек немесе none]
limitations: [не расталмаған]
```

Техникалық тексеру нәтижесі конкурс балын анықтамайды және жұмысқа пайдалануға дайын екенін растамайды.
